# Expense Tracker & Budget Analyzer

A command-line tool to track spending against category budgets, log income, 
and analyze spending patterns over time.

## Features
- Set budgets per category and log expenses against them
- Automatic warnings when approaching or exceeding budget (80%/100% thresholds)
- Income tracking and net calculation (income vs. spending) per month/year
- Month-to-month and year-to-year spending comparisons
- Detects which category is overspent the most
- Data persists between runs using JSON file storage

## How to run
python expense_tracker.py

## Built with
Python (datetime, json)
